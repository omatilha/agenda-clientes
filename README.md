# 📇 AgendaPro - Sistema de Gestão e Cadastro de Clientes

Sistema moderno, leve e responsivo para cadastro, busca e gerenciamento de clientes e contatos. Desenvolvido em HTML5, Tailwind CSS e Vanilla JavaScript, pronto para ser hospedado no **GitHub Pages**.

---

## ✨ Funcionalidades

- **Cadastro Completo**: Nome, WhatsApp/Telefone (com máscara), e-mail, categoria, data de nascimento, cidade, status e histórico/observações.
- **Ações Rápidas**:
  - Iniciar conversa no WhatsApp com 1 clique (`wa.me`).
  - Disparo de e-mail direto.
  - Edição e exclusão com modal de confirmação.
- **Painel de Indicadores (Dashboard)**:
  - Total de clientes cadastrados.
  - Clientes ativos.
  - Contatos com WhatsApp.
  - Aniversariantes do mês atual.
- **Filtros e Busca em Tempo Real**: Filtro instantâneo por texto, categorias (*Particular, Convênio, VIP, etc.*) e status (*Ativo / Inativo*).
- **Persistência de Dados**: Salva automaticamente no `localStorage` do navegador.
- **Exportação para CSV**: Permite baixar os dados em formato de planilha compatível com Excel e Google Planilhas.

---

## 🚀 Como Executar Localmente

Não requer instalação de dependências ou servidores.
Basta abrir o arquivo `index.html` em qualquer navegador moderno.

---

## 🌐 Publicação no GitHub Pages

Para disponibilizar o sistema online gratuitamente:
1. No repositório no GitHub, vá em **Settings** (Configurações).
2. No menu lateral esquerdo, clique em **Pages**.
3. Em **Branch**, selecione `main` (ou `master`) e a pasta `/(root)`.
4. Clique em **Save**. Em instantes, seu sistema estará acessível pelo link gerado pelo GitHub Pages.
